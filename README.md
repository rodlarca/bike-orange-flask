# Bike Orange – Prototipo Funcional (Flask)

Este proyecto corresponde a un **mockup de prototipo funcional** desarrollado para el caso *“Experiencias de usuarios para Bike Orange”*, en el contexto del ramo **ISI601 – Taller de Diseño de Sistemas**.

La solución representa una **aplicación web simple**, orientada a mejorar la experiencia de turistas y ciudadanos que desean recorrer la ciudad de Santiago en bicicleta, mediante una navegación clara e intuitiva.

## 🧩 Características del prototipo
- Desarrollo en **Flask**, utilizando **HTML y Bootstrap**.
- Flujo principal de navegación:
  - Inicio y selección de perfil de usuario.
  - Selección de experiencias.
  - Detalle de ruta.
  - Evaluación de la experiencia.
- Diseño centrado en el usuario y viable de implementar en el corto plazo.
- No incluye lógica de negocio ni persistencia de datos (mockup).
